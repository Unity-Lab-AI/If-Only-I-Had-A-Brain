Unity's brain thinks and speaks entirely from its own equations + dictionary + neural dynamics. All text AI model connections have been removed from the cognition path.

**Current state (realized):** README.md top paragraph states *"Cognition is 100% equational — no text-AI backend."* Language production runs through the T14 tick-driven motor emission loop (cortex cross-projection propagate → motor region argmax per tick → letter commit on quiescence). Zero slot scorers, zero stored sentences, zero n-gram tables, zero softmax text sampling, zero transformer calls.

**Only external AI allowed:** IMAGE generation (Pollinations, flux, custom backends) + vision describer (Pollinations GPT-4o as a V1→V4→IT sensory peripheral) + TTS voice output. These are SENSORY peripherals — they feed into or emit from the cortex state, but they don't generate cognition.

**How to apply:** When building features, never create dependencies on AI text responses. Language production must work from brain equations alone. Image generation can stay external. Any PR that adds a "call AI to decide what Unity should say" path violates project scope.
