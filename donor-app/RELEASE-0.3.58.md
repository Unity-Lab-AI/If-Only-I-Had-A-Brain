# Donor 0.3.58

- **A cell hears its wiring.** Each cluster has a buffer that holds, for every cell, the summed weight of its inputs from cells that fired the step before. At the top of each step the buffer is cleared and every matrix bound into the cluster adds to it (the existing propagate kernel, reading the source cluster's spikes at the bound offsets); the step then adds `gain × that input` to the cell's fast variable. Gain 0 — the default — is the step exactly as it was. Both backends, same arithmetic.
- **A rest setting.** `σ = −1 − rest + 1.5 · clamp(drive / 40, 0, 1)`. With `rest = 0` nothing changes. Lowered far enough, a cell with no input is silent.
- **New message `delivery`** — `{"type":"delivery","clusters":[{"name":…,"gain":…,"restShift":…}]}` — sets both per cluster and is answered by `delivery_ack` with the clusters resident on this donor. The setting is kept by cluster name, so a cluster built again (a move, a reconnect) steps the way the brain last asked. A brain that never sends it sees no change.
- **Error-driven plasticity** (`plasticity_mode`, sent by a brain whose pathways learn only when a cell is wrong): the step is now the gap-closing one — each lit wire of a wrong cell takes an equal share of what the cell is short of, or over by — and a launch can be limited to a span of rows. `plasticity_mode` takes optional `spans` (the brain's region table) so a lesson inside one region sweeps that region's rows only. Default step size is the whole gap.
- **`hebbian_ranges` accepts 4,096 index runs a side** (was 16). A word's own cells are about 150 runs; at 16 no word fitted.
- **Fixed: the wgpu per-cell spike readback returned zeros.** The spike buffer could not be copied out, and the validation error was logged and swallowed. It can now.
- **Self-test** gained the delivery check (taught cells firing against others, across rest settings, drives and gains, on both backends, with the step terms the brain sends) and the error-driven parity, mode and row-span checks. On the reference card: 11 of 11 weights match the host rule on both backends; with rest 1.75 and gain 5, 54.0 of 54 taught target cells fire one step after their source pattern is lit, against 0.7 of the other 1,946.
- `kernels.ptx` regenerated (`sm_75`, 11 entry points): `lif` takes the wiring buffer, gain and rest; `plasticity_error` takes a row span.
